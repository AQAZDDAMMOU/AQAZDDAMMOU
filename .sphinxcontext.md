# Project context for Sphinx

## About this project
A collection of Claude Code skills (`.claude/skills/*/SKILL.md` plus their references, scripts and data) and a `CLAUDE.md` routing rule. The main use is producing scientific figures (graphical abstracts, TOC graphics, multi-panel figures, schematics) as editable SVG/PPTX, plus UI/design/branding skills. Most skills are vendored from upstream projects; the CLAUDE.md routing rules and skill trigger descriptions are the parts edited here.

## What to ask about
- Focus on which skill a request triggers and how CLAUDE.md routes figure requests.
- Don't ask about vendored data files, fonts, or wording-only edits in reference docs.
